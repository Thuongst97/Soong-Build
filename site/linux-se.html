Module 14 · Head-unit SoC

Linux SE Guest with Yocto

The Linux SE VM is the head unit's “mail room”: it talks to the cloud, the telematics box and the diagnostic tester, so Android doesn't have to. It is small, read-only and runs with SELinux enforcing. It's built with the Yocto Project — a third, completely different build system from Soong.

⏱ 25 min read🎯 Intermediate → Advanced🧰 Yocto · BitBake · meta-selinux

14.1What the Linux SE VM does

ServiceWhy it lives here and not in Android
Telematics & cellular linkAlways-on connectivity independent of the Android lifecycle (Android may be suspended or restarting).
OTA orchestratorDownloads and verifies updates for all VMs and coordinates slot switches (Module 15.7).
Firewall / gatewaySingle, hardened entry point between external networks and the in-vehicle network.
Diagnostics (DoIP/UDS)Workshop tester access with its own authentication.
Logging & crash uploadCollects logs from all VMs even when Android is down.
ℹ️
Naming

“Linux SE” here means a security-enhanced (SELinux-enforcing) Linux guest. If your program uses the name for a different service VM, everything below still applies — only the package list changes.

14.2Setting up Yocto

💡
Tip

Use an LTS release (Scarthgap 5.0 here) for a vehicle program and pin every layer to a commit. Tools such as kas or a repo manifest make the layer set reproducible, exactly like the Android manifest in Module 02.

14.3Layers

Yocto is composed of layers of recipes. Never edit upstream layers — put every change in your own meta-acme using .bbappend files.

meta-acme/ ├── conf/layer.conf ├── conf/machine/acme-hu-vm.conf # 14.4 ├── conf/distro/acme-se.conf # 14.5 ├── recipes-kernel/linux/linux-yocto_%.bbappend + files/virtio-guest.cfg ├── recipes-core/images/acme-linux-se-image.bb # 14.6 └── recipes-acme/acme-telematics/ acme-ota-orchestrator/ acme-diag-gateway/

14.4A machine for the VM

The “machine” is the virtual hardware from linux.qvmconf (Module 11.5): virtio-mmio devices, a hvc0 console, no real peripherals except the passed-through Ethernet MAC.

14.5Enabling SELinux

meta-selinux provides the userspace, a reference policy and the kernel configuration. Turn it on in a small distro config so it can never be forgotten in local.conf.
