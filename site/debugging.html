7.4Common errors and fixes

Message (abridged)CauseFix
depends on undefined module "X"Typo, missing repo, or X lives in a namespace not in PRODUCT_SOONG_NAMESPACES.mgrep '"X"'; add the namespace or the project to your local manifest.
module "X" already definedTwo Android.bp files define the same name in one namespace.Rename, or put one tree in its own soong_namespace.
unrecognized property "foo"Typo, wrong module type, or property removed in this Android version.Check the generated module reference for your branch.
dependency "libX" … variant "vendor" not foundA vendor module links a system-only library.Use an LLNDK/vendor-available lib, or mark yours vendor_available.
neverallow … violatedYour SEPolicy grants something forbidden platform-wide.Redesign the access (Module 13.8); never patch the neverallow.
Offending entries … artifact path requirementsThe product installs files into /system outside what the base product allows.Move the module to /product or /vendor.
… image too large / Out of spacePartition contents exceed BOARD_*_SIZE or the super group size.Re-budget sizes in BoardConfig.mk (and the GPT, Module 15).
missing and no known rule to make itA file was deleted, or a genrule output is not declared in out:.Fix the reference; declare every output.
Random Killed / signal 9The kernel OOM killer.Lower -j, add swap, or add RAM.

7.5Making builds faster

Build less

m <module> while iterating, m <partition>image before flashing one partition, full m only before integration.

Don't regenerate

Touching any Android.bp or makefile re-runs Soong/Kati (minutes). Batch build-file edits; validate them with m nothing.

Cache compilation

USE_CCACHE=1, CCACHE_EXEC=/usr/bin/ccache, a 50–100 GB cache on NVMe shared between branches of the same release.

Distribute

Remote build execution (USE_RBE=1 with reclient) scales a build across a cluster; it needs a compatible backend service.

💡
Tip

Load out/build.trace.gz into Perfetto after a slow CI build. Long single-threaded stretches are usually Soong/Kati regeneration, R8/D8 on big apps, or image generation — each has a different remedy.

7.6Clean builds without nuking everything

WhenDo
Changed PRODUCT_*/BOARD_*, or a file should no longer be installedm installclean — removes staging dirs and images, keeps object files.
One module behaves strangelyrm -rf out/soong/.intermediates/<path>/<module>, rebuild it.
Switching to a very different branch or Android versionm clobber (or a separate OUT_DIR per branch).
